Install CA Certificate

To inspect HTTPS traffic, install the LocalApiWebProxy CA certificate on each device. Do this once per device — then all HTTPS traffic appears in the dashboard.

Download CA Certificate
LocalApiWebProxy.crt
macOSDesktop
  1. Download the CA cert above
  2. Double-click LocalApiWebProxy.crt — Keychain Access opens
  3. Find LocalApiWebProxy CA → double-click → expand Trust
  4. Set When using this certificate → Always Trust
  5. Close and enter your password
WindowsDesktop
  1. Download the CA cert above
  2. Double-click LocalApiWebProxy.crt → Install Certificate
  3. Choose Local Machine → Next
  4. Select Place all certificates in the following store
  5. Browse → Trusted Root Certification Authorities → OK → Finish
  6. Restart your browser
iPhone / iPadiOS
  1. On the device, open Safari and go to:
    http://<your-ip>:8000/ca.crt
  2. Tap Allow when prompted to download profile
  3. Settings → General → VPN & Device Management
  4. Tap LocalApiWebProxy CA → Install → enter passcode
  5. Settings → General → About → Certificate Trust Settings
  6. Toggle LocalApiWebProxy CA to ON → Continue
AndroidAndroid
  1. On the device open Chrome and go to:
    http://<your-ip>:8000/ca.crt
  2. Download the file
  3. Settings → Security → Encryption & credentials
  4. Tap Install a certificate → CA certificate
  5. Select the downloaded LocalApiWebProxy.crt → Install anyway
  6. Note: Chrome browser trusts user CAs. Most apps with certificate pinning will not.
