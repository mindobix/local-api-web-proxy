LocalApiWebProxy

A zero-config HTTP/HTTPS proxy with a real-time dashboard. Inspect, debug, and export API traffic from any device on your network — like Charles Proxy, but open-source and a single npm start.

▶ Open Dashboard localhost:8000 ↗ GitHub
Ports
8888
Proxy
Point your device's HTTP/HTTPS proxy here to intercept traffic
8000
Dashboard
Live request viewer — open in any browser on the network
Features
⚡
Real-Time Dashboard
Requests stream in live via WebSocket as they happen — no polling, no refresh.
🔐
HTTP + HTTPS MITM
Full man-in-the-middle proxy with per-domain TLS certificate generation using node-forge.
🗂️
Domains + Timeline Views
Browse captured traffic grouped by host, or in a flat chronological timeline.
🔍
Smart Filter
Type 401, post, or any hostname/path/body text to narrow the view instantly.
📤
HAR Export
Export any filtered subset as a standard .har file — compatible with Chrome DevTools, Postman, and Charles.
📋
cURL Copy
One click to copy any captured request as a ready-to-run curl command.
🖼️
Image Preview
Binary image responses render inline in the Response tab — no external viewer needed.
⏸️
Pause / Resume
Stop recording without losing captured traffic. Press Space to toggle.
📱
Multi-Device
Proxy traffic from phones, tablets, simulators, or any machine on your LAN — built-in CA setup guide for all platforms.
🔄
Auto Port Recovery
If the port is in use, the old process is killed automatically and the server retakes it — no manual kill needed.
✨
JSON Pretty-Print
Request and response bodies are syntax-highlighted with a one-click JSON toggle for raw vs. formatted views.
🔒
Zero Cloud
No telemetry, no accounts, no relay servers. All traffic stays on your machine and LAN.
How to Run
⚙️
Getting Started
1
Requirements
Node.js 18 or later and npm. No build step — the frontend is vanilla JS.
2
Install dependencies
npm install
3
Start the proxy
npm run dev # or: npm start — same thing
Two servers start immediately:
# Dashboard → open this in your browser http://localhost:8000 # Proxy → point devices here http://<your-ip>:8888
4
Configure your device's proxy
Set the WiFi/HTTP proxy on each device to <your-machine-ip>:8888:
Device Where to set it
🍎 macOS System Settings → Network → Proxies → Web Proxy + Secure Web Proxy
🪟 Windows Settings → Network & Internet → Proxy → Manual proxy setup
📱 iOS WiFi → tap network → HTTP Proxy → Manual
🤖 Android WiFi → long-press network → Modify → Advanced → Proxy → Manual
5
Install the CA certificate (HTTPS only)
To inspect HTTPS traffic, open the dashboard on your device and click CA Setup. Download and install LocalApiWebProxy.crt — the page walks through installation for every platform. One-time per device.
6
Custom ports (optional)
# via env vars PROXY_PORT=9999 DASH_PORT=9000 npm run start:custom # via flags node server.js --proxy-port 9999 --dashboard-port 9000 # shorthand node server.js -p 9999 -d 9000
